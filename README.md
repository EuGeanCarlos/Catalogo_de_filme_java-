# Catálogo de filmes — estudos Java

Exercícios introdutórios de Java com variáveis, condicionais, leitura pelo terminal e desafio de programação.

## Tecnologias

- Java
- Scanner

## Funcionalidades e utilização

Execute Main para o exemplo principal; src/ contém também Leitura, Condicional e br.packge_atividade.Desafio.

## Como executar

```bash
git clone https://github.com/EuGeanCarlos/Catalogo_de_filme_java-.git
cd Catalogo_de_filme_java-
javac -encoding UTF-8 -d out src/Condicional.java src/Leitura.java src/Main.java src/br/packge_atividade/Desafio.java
java -cp out Main
```

Requer JDK 17 ou superior. Os exercícios executam no terminal.

## Demonstração e publicação

Execução local. Nenhuma demonstração nova foi confirmada nesta etapa.
